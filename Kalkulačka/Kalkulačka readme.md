Interactive CLI Calculator with Exception Handling (Python)

A feature-rich command-line calculator built in Python. Demonstrates input validation, robust exception handling, mathematical functions, and interactive program flow.

Features:

- Core Arithmetic Operations: Addition, Subtraction, Multiplication, Division, and Exponentiation.
- Defensive Programming & Exception Handling:
- Gracefully handles invalid user inputs (e.g., text instead of numbers) using `try / except` blocks (`ValueError`).
- Safe Division Logic: Prevents runtime crashes on division by zero (`ZeroDivisionError` prevention).
- Interactive Menu Loop: Keeps the application running for multiple continuous calculations.

Concepts & Technologies Used:

- Language: Python 3.12+
- Error Handling: `try / except` blocks
- Functions: Modular function design for each operation
- Control Flow: `while` loops, input validation using list lookups

How to Run:
